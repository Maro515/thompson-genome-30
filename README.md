# トンプソン遺伝医学・ゲノム医学 30日ゼミ

**https://maro515.github.io/thompson-genome-30/**

## 構成

原著全20章を30レッスンに割り付け、6つの Part にまとめてある。

| Part | Day | 章 | テーマ |
|---|---|---|---|
| 1 | 1–5 | 第1〜3章 | ゲノムという設計図を読む |
| 2 | 6–10 | 第4〜6章 | 多様性・バリアントと染色体診断 |
| 3 | 11–15 | 第7〜9章 | 遺伝形式・エピジェネティクス・多因子疾患 |
| 4 | 16–20 | 第10〜12章 | 集団遺伝学と疾患遺伝子の同定 |
| 5 | 21–24 | 第13〜15章 | 病態の分子メカニズムと治療、発生 |
| 6 | 25–30 | 第16〜20章 | がんゲノム、臨床実装、倫理 |

各レッスン = 学習目標 → キーワード → 会話本文（図解・臨床メモ・たとえ話つき）
→ まとめ → 症例提示へのリンク → 確認クイズ5問 → 一問一答 → 前日までの復習（自動生成）。

## パート修了エピソード

各 Part の最終日（Day 5 / 10 / 15 / 20 / 24 / 30）の末尾に、そのパートの内容が実際の科学史の
なかでどう働いたかを見せる読み物を1本ずつ置いてある。`#/episode/1`〜`6` で単独でも読める。

| Part | エピソード | 何を思い出させるか |
|---|---|---|
| 1 | 写真51番 — 誰が二重らせんを「見た」のか | 構造が機能を説明する／功績の帰属 |
| 2 | 46本と数えられるまでの33年 | 解像度が診断を決める／確証バイアス |
| 3 | 王家の血友病 | X連鎖潜性の家系図を実際に読む |
| 4 | マラカイボ湖の家系図 | 創始者効果・連鎖解析・研究倫理 |
| 5 | Guthrie のろ紙 | 発症前に介入する検査という発想 |
| 6 | 不死の細胞と、知らされなかった家族 | がん・同意・プライバシー・正義 |

教科書の外の題材なので、**本編より厳しい精度ルール**で書いてある（`build/EPISODE_SPEC.md`）。
年号・人名・論文誌名は裏取りのうえ、確定できないものは断定を外し、各話末尾の `caution` に
留保を明記している。ソースは `build/episodes/epN.json`。

## 使い方

1. `index.html` を開く（ブラウザにドラッグ＆ドロップでもよい）
2. Day の冒頭に書かれた**教科書のページを実際に開いて併読する**
3. 会話を読む → クイズを解く → まとめを読む → 一問一答を声に出す
4. 「学習完了にする」を押すと自動で次の日へ

進捗（読了・クイズ結果）は開いた端末のブラウザ内 localStorage にのみ保存される。

キーボード: `/` 検索 · `j` / `→` 次の日 · `k` / `←` 前の日 · `Esc` 閉じる

## デザイン

**ポップ版**（2026-07-31 に刷新）。見出しは**ヒラギノ丸ゴシック**、本文はヒラギノ角ゴ **17px**（旧15px）。
クリーム色の点描紙に、3px の輪郭線とハードシャドウを載せた「ステッカー」調。

- **Part 1〜6 を色分け**（スカイ／リーフ／グレープ／ペア／プラム／コーラル）。Day カード・見出し・
  パンくず・ト書きの縦線まで、そのパートの色が通る
- 会話は**しっぽ付きの吹き出し**。5人のキャラクターごとに地色が違う
- 完了した Day には緑の**✓ステッカー**が斜めに付く
- 文字サイズは `Aa` ボタンで 17 → 19 → 21px の3段階
- ライト／ダーク両対応。**両テーマとも本文コントラスト 4.5:1 以上を実測で確認**

デザインの実体は `build/pop.css`（旧エディトリアル版は `build/shell.editorial.bak.html` に保存）。
色を変えたいときは `:root` のトークン（`--color-accent`, `--p1`〜`--p6` など）だけ触れば全体に反映される。
アクセント色の上に載る文字は必ず `--color-on-accent` を使うこと（テーマごとに明暗が反転する）。

## 内容を直したいとき

`index.html` の中の `const DAYS = [ ... ]` が全レッスンのデータ。JSONなので直接編集できる。
ただし**ソースから作り直すほうが安全**:

```bash
python3 build/assemble.py
```

- `build/shell.html` … UI（CSS・レンダラ・ルータ）。`const DAYS = /*__DAYS__*/[];` の位置にデータが差し込まれる
- `build/days/dayNN.json` … 各日の内容。1ファイル1レッスン
- `build/plan.json` … 30日の割り付け（章・節・ページ・タイトル・扱う項目）と Part 定義
- `build/SPEC.md` … レッスンを書くための仕様（スキーマ・図の型・文体）
- `build/CASES.md` … 教科書「症例提示」49例の一覧
- `build/ocr/chNN.txt` … 原著PDFから抽出した章別テキスト。**著作物の複製なので `.gitignore` で公開対象から除外**
  （手元にのみ存在。`pdftotext -layout` で再生成できる）

`assemble.py` は組み立て時に検証も行う（クイズの正答インデックス、表の列数、家系図のノード参照、
話者キー、必要な要素数）。エラーが出たら該当 `dayNN.json` を直して再実行する。

## 図の型

`build/SPEC.md` 参照。`flow`（順序）/ `compare`（対比）/ `table` / `stack`（階層）/
`pedigree`（家系図）/ `formula`（数式）/ `seq`（塩基配列＋マーカー）/ `bars`（量的比較）/ `svg`。
すべて外部ライブラリなしで描画される。
